# learn_flutter_sdk
flutter/flutter の学習リポジトリ

## Flutter SDK

このリポジトリには Flutter SDK version 3.38.6 が含まれています。

- **場所**: `root/flutter_sdk/`
- **バージョン**: 3.38.6
- **リリース**: https://github.com/flutter/flutter/releases/tag/3.38.6

### サブモジュールの初期化

リポジトリをクローンした後、以下のコマンドでサブモジュールを初期化してください：

```bash
git submodule update --init --recursive
```
